# All about Route53  
AWS Route 53 is a DNS service that combines all the Internet traffic to the appropriate servers to the host as well as the required application from the web.  
We can buy public domain names for our website/web applications or Private domain names that can be resolved by our instances in our created VPCs.  
Besides, Route53 offers various AWS resources such as Load balancing, Health checks, and Routing policies like Simple, Failover, Geolocation, Latency, Weighted, Multi-value. Moreover, In AWS Route53, we have many types of records.
