# All about IAM's, Roles and related configuration!  

## What is AssumeRole in AWS?  
AssumeRole is an AWS STS (Security Token Service) API action that lets one identity temporarily take permissions of another IAM role.  
AssumeRole = “Act as this other role for some time.”
